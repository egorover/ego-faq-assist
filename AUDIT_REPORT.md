# Аудит исходного проекта

Источник: публичный репозиторий [MrGAN12009/pcef9](https://github.com/MrGAN12009/pcef9), README, `requirements.txt`, `backend/app.py`, `backend/build_index.py`, `backend/rag_index.py`, FAQ JSON и frontend.

## Архитектура и использованные идеи

- FastAPI предоставляет `/chat` и `/health`.
- Скрипт собирает FAQ JSON и TXT, вычисляет embeddings, индексирует документы в FAISS, хранит metadata.
- Виджет отправляет запросы backend и отображает ответ.
- MVP сохраняет этот общий pipeline, но написан модульно и добавляет необходимые требования по провайдерам, сессиям, порогу и безопасности. Код исходника не перенесен.

## Обнаруженные проблемы исходного проекта

- API key обязателен при импорте приложения, поэтому без credentials нельзя даже запустить health endpoint.
- OpenAI client, модель embeddings и chat-модель жестко заданы; provider abstraction отсутствует.
- CORS открыт на `*` с включенными credentials.
- FAISS L2 поиск не нормализует embeddings; similarity threshold отсутствует и расстояния игнорируются.
- Нет памяти между сообщениями, ограничения размеров ввода, сессий и обработки ошибок внешнего API.
- TXT загрузчик подавляет ошибки чтения; metadata `.npy` загружается с `allow_pickle=True`.
- Нет автоматических тестов, устойчивой валидации форматов и источников в ответе API.
- README описывает потенциальный KPI без доступных измерений; это не подтверждает KPI проекта.
